# 项目计划、周期评估与三人分工

**项目名称**：Chronicle of the Lost Realms（Zuul 拓展 + 像素 RPG 客户端）  
**团队规模**：3 人  
**文档版本**：2.1  
**日期**：2026-05-25  

---

## 一、拓展方案总览

| 亮点 | 玩家感受 | 技术要点 |
|------|----------|----------|
| **像素世界** | 俯视角行走、场景过渡 | LibGDX + Tiled + PlayerSprite |
| **地图互动** | 靠近显示 E 提示 | InteractionHintSystem |
| **多结局叙事** | 光明/暗影/中立 | QuestManager + EndingEvaluator |
| **NPC 社会链** | 对话、交易 | talkNpc + DialogueBox + JSON |
| **环境谜题** | 火把/钥匙/门 | UseEffect + 碰撞更新 |
| **探索小地图** | 只显示已探索 | ExplorationTracker + MiniMap |
| **传送房间** | 进入密室被随机甩到别处 | isTeleport + randomRoomExcept |
| **完整存档** | 菜单存读档 | GameState 含坐标与 entryDirection |
| **GUI 唯一入口** | 答辩直接运行 RpgMain | 无 CLI 交付 |

## 六、协作规范

1. **Commit 前缀**：`feat(world)` / `feat(engine)` / `feat(client)` / `test` / `ci` / `docs`  
2. **接口冻结**：  
   - **第 1 周末**：`GameEngine` API 草案（B 发 PR，C 评审）  
   - **第 2 周末**：API + Tiled 对象命名 + 对话 JSON **定稿**  
3. **Review**：Engine 改动 B；GameScreen C；tmx A  
4. **Issues**：一任务一 Issue，commit 引用 `#n`  
5. **Actions**：feature 分支 compile+checkstyle；master 加 test+package
