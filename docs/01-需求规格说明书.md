**基线代码**：World of Zuul（Java 文本冒险游戏）

## 1. 引言

### 1.1 编写目的

本文档定义三人小组在 World of Zuul 基础上进行功能拓展的**功能需求**与**非功能需求**，作为设计、开发、测试与验收的统一依据。v2.1 起，项目以 **LibGDX 像素 RPG 客户端为唯一交互入口**，所有玩法通过键鼠与 GUI 完成；原 Zuul 文本命令仅作为 README 语义对照，不单独交付 CLI 程序。

### 1.2 项目背景

World of Zuul 是经典的「房间 + 方向移动 + 物品拾取」文本冒险框架。课程实验要求在此基础上增加新命令、新机制并完成团队协作开发。本方案将游戏升级为像素 RPG 客户端。

**需求分层说明**：

| 层次 | 内容 | 来源 |
|------|------|------|
| **README 基础** | look / back / 高级 back / 传送房间 / Player + take + drop + items + eat cookie 负重系统 / GUI | README §2 参考项 1–5 + 7 |
| **自主扩展** | 像素行走动画 / 碰撞检测 / 互动提示 / 对话树 / HUD / 背包面板 / 多结局 / 任务系统 / 谜题 / 存档 | 团队自主设计 |
| **未实现** | 网络多人（参考项 6）/ 数据库（参考项 8） | 用 JSON 存档替代数据库 |

- **视觉层**：16-bit 风格像素贴图、平滑人物行走、地图互动提示、对话框与 HUD；
- **逻辑层**：多结局叙事、NPC 社交、谜题机关、持久化存档；
- **工程层**：Java 单体 + 分层架构，领域逻辑与表现层解耦，便于三人并行。

### 1.3 术语与缩写

| 术语 | 说明 |
|------|------|
| Room | 房间/场景，逻辑上的空间单元，对应一张 Tiled 子地图 |
| Item | 可拾取、可使用的物品，在地图上以精灵或图块表示 |
| NPC | 非玩家角色，可对话、可交易，带站立动画（可选） |
| GameEngine | 无 UI 依赖的游戏核心；GUI 通过其公开 API 驱动状态 |
| Tiled | 开源地图编辑器，产出 `.tmx` 瓦片地图 |
| LibGDX | Java 2D 游戏框架，负责渲染、输入与资源管理 |
| Interactable | 地图上可交互实体（物品、NPC、机关、出口） |
| Save/Load | 存档/读档，将动态游戏状态序列化到文件 |

## 2. 总体描述

### 2.1 产品愿景

玩家扮演「Realm 编年史者」，在**可自由行走的像素世界**中探索互联场景：走近物品/NPC/机关时出现互动提示，按键触发拾取、对话、使用道具；穿越场景边界或指定出口切换房间。根据**声望值**与**关键抉择**进入不同结局。整体体验对标经典 2D RPG 俯视角房间制探索。

### 2.2 用户特征

| 用户 | 使用方式 |
|------|----------|
| 玩家 / 评审者 | 运行 `RpgMain`，键鼠操作 |
| 内容作者（成员 A） | 使用 Tiled 编辑 `.tmx`，配置碰撞层与对象层 |

### 2.3 运行环境

| 项目 | 要求 |
|------|------|
| 语言 | Java 8+（推荐 11） |
| 构建 | Maven（`pom.xml`） |
| GUI 框架 | LibGDX 1.12.x（Desktop 后端） |
| 地图工具 | Tiled 1.10+，导出格式 XML `.tmx` |
| 像素规格 | 基础图块 **32×32** px；窗口默认 **960×540** |
| 资源 | `assets/`：tilesets、sprites、maps、ui、fonts、dialogue |
| 存档 | `./saves/*.json` 或 `.sav`；不含贴图等大资源 |
| 编码 | UTF-8，对话框支持中文 |

### 2.4 约束与假设

- **唯一入口**：仅交付 GUI 客户端（`RpgMain`），不维护独立 CLI 可执行程序
- 不采用 Web 前后端分离；全部为 **Java 进程内** 分层
- 不开发网络多人（本期）；音效为 P2 可选
- 三人 Git 三分支并行，最终合并至 `master`
- 美术可使用开源像素包（README 注明出处），允许占位图先行

## 3. 功能需求

### 3.1 图形界面 — 像素 RPG 客户端（FR-GUI，P0）

| ID | 需求描述 | 验收标准 |
|----|----------|----------|
| FR-G01 | **俯视角像素场景渲染** | 当前 Room 加载对应 Tiled 地图；分层绘制；最近邻滤波无模糊 |
| FR-G02 | **玩家精灵与四方向行走** | 行走图 ≥4 方向；WASD/方向键移动；碰撞层不可通行 |
| FR-G03 | **房间切换** | 进入出口区触发 `movePlayer`；淡入淡出 ≤0.5s |
| FR-G04 | **互动提示** | 靠近 Interactable（≤1.5 格）显示「E 互动」等；离开消失 |
| FR-G05 | **互动操作** | `E`/点击调用 `GameEngine.takeItem` / `talkNpc` / `useItem` 等，语义同 README 命令 |
| FR-G06 | **对话框 UI** | 底部文本框、分支选项；Space/Enter 翻页 |
| FR-G07 | **HUD** | HP、声望、小地图/roomId；`I` 背包 |
| FR-G08 | **菜单** | ESC：继续、存档、读档、返回标题、退出 |
| FR-G09 | **标题与结局** | 标题屏：**输入玩家姓名**、新游戏/读档；结局全屏卡 |
| FR-G10 | **死亡画面** | HP≤0 时全屏提示；可选「读档」「返回标题」 |

### 3.2 基础命令（README 必做 — FR-BASE）

> 下列 README 命令均映射为 `GameEngine` API + GUI 操作，见 `02` §12。

| ID | 需求描述 | GUI 映射 | 验收标准 |
|----|----------|----------|----------|
| FR-B01 | `look` 增强 | 进房自动旁白；`Q` 调查 | 描述、出口、地面物品、NPC |
| FR-B02 | `take` / `drop` | `E` 拾取；背包丢弃单件/全部 | 转移正确；支持 drop all |
| FR-B03 | `items` | `I` 背包面板 | **房间**物品+总重、**背包**物品+总重 |
| FR-B04 | `eat cookie` | 背包使用 magic cookie | **maxWeight +20**，物品消失 |
| FR-B05 | `back`（高级） | `B` 或菜单 | **逐层**回退 roomHistory |
| FR-B06 | `help` | ESC 帮助页 | 键位与玩法说明 |

| ID | 需求描述 | 优先级 | GUI 映射 | 验收标准 |

## 4. 非功能需求

### 4.1 性能（NFR-P）

- GUI **≥ 60 FPS**；场景切换 **< 500ms**；互动逻辑 **< 16ms/次**
- 存档 **< 512KB**

### 4.2 可维护性（NFR-M）

- `GameEngine` **不依赖** LibGDX
- 新 Room：Tiled + `WorldFactory` 注册

### 4.3 可靠性（NFR-R）

- 非法操作友好提示；资源缺失用占位图；load 失败不丢内存态

### 4.4 可测试性（NFR-T）

- **`GameEngine` 单元测试**（JUnit，无图形窗口）：移动、拾取超重、传送、back、存档往返
- 核心 API 覆盖率建议 ≥ 60%（move/take/drop/use/quest）

### 4.5 表现与体验（NFR-UX）

- 像素风格统一；互动提示 ≤100ms；整数倍窗口缩放

### 4.6 协作（NFR-C）

- 三分支并行；`client` 包由 C 主责
