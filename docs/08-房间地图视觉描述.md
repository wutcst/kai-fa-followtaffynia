# 失落 Realm 编年史 —— 15 房间地图视觉描述

> 用于 AI 图像生成辅助。风格：16×16 像素艺术，城堡地牢主题，暗色调。

---

## 全局风格规范

- **瓦片尺寸**：16×16 像素
- **墙壁**：深灰石砖（#3a3a4a / #2a2a38），顶部有轻微苔藓（#4a5a3a）
- **地板**：不规则石板（#4a4a52 / #3a3a42），缝隙间有暗色填充
- **光源**：墙上火把（#e8a030 火焰 + #404040 金属支架），橙色光晕半径 3-4 格
- **门**：深色橡木门（#6a4a2a），铁质把手（#808080），方向依出口而定
- **上锁的门**：同门但附加铁链/挂锁（#909090 金属）
- **物品**：宝箱（#8a6a3a 木头 + #c0a030 金属边）、木桶（#7a5a3a）、书架（#6a4a2a）
- **NPC**：色块占位——守卫（#cc4444 红）、隐士（#4488cc 蓝）、商人（#ccaa22 金）
- **氛围**：整体偏暗，火把是唯一光源，墙壁边缘有阴影渐变。

## 1. outside — 地牢入口广场

```
房间职能：游戏起点，枢纽广场
出口：北(theatre) / 南(lab) / 东(pub) / 西(office)
物品：welcome-note（一张皱纸条），放在地上靠近出生点
```

**布局描述**：
一个 30×16 格的露天石砌广场。四壁是古老的城堡石墙，但顶部有破损——几缕天光从裂缝中漏下（#6a7a8a 淡蓝灰光线）。地板是破裂的石板，中央有一块略微下陷的圆形石板（#5a5a5a）。北墙和南墙各有大型橡木门，东墙和西墙是较小的拱门。出生点（玩家出现位置）在广场中央偏下一格——地上散落着一小片皱巴巴的羊皮纸（welcome-note，#d8c898 羊皮纸色，2×2 像素点）。四个墙角各有一支插在铁架上的火把，火光照亮周围 3 格半径。墙上偶尔有藤蔓（#4a6a3a）垂挂。

## 2. theatre — 废弃讲堂

```
房间职能：连接枢纽
出口：南(outside) / 东(library)
物品：torch（火把），立在东墙角
```

**布局描述**：
一间阶梯状的废弃讲堂，约 30×16 格。北侧是三级石阶逐级升高（#4a4a4a → #555555），像一个小型讲坛。墙壁是深色石砖，高处有破损的挂毯残片（#6a3a3a 暗红色，边缘破烂）。东墙角立着一根未点燃的火把（torch），靠在墙边——木质手柄（#8a6a3a），顶端包裹着浸油布（#c8c0a0）。地板是石板，但有几处裂纹。南墙的门通向外面的广场，东墙的拱门通向图书馆——拱门上方有一块模糊的浮雕（#555555）。天花板上悬着一根生锈的铁链吊灯（未点亮）。

## 3. pub — 废弃酒馆

```
房间职能：连接枢纽

物品：ale-mug（半杯麦酒），放在翻倒的桌子上
```

**布局描述**：
曾经热闹的酒馆，现在破败不堪。约 30×16 格。房间中央有一张翻倒的橡木长桌（#6a4a2a），桌腿朝天。桌上放着半杯残留的麦酒——一个陶制酒杯（ale-mug，#8a7a5a，高 4 格），杯中有深琥珀色液体（#a08030），杯口有细微泡沫。北墙有一排空酒桶（#7a5a3a × 3 个），其中一个裂开了。南墙的门通向地窖——门框上方有木制招牌残片（#6a4a2a，字迹模糊）。东墙的拱门通向花园，隐约可以看到绿色。地板是木质的（#5a4a3a），有几处腐烂的痕迹。墙角有蜘蛛网（#888888）。

**布局描述**：
一间被遗弃的炼金术士工坊，约 30×16 格。西墙有一排木制实验台（#6a4a2a），上面散落着玻璃器皿——烧瓶（#88aacc 半透明蓝，3×4 格）、蒸馏器（#888888 金属）、几页散落的笔记（#d8c898）。实验台上显眼地放着一把锈迹斑斑的钥匙（key-vault，#a08040 金属锈色，4×2 格）——这就是通往金库的钥匙。南墙是一扇沉重的大铁门（#909090），上面挂着铁锁链（locked）——门框上方刻着 "VAULT" 字样（#808080）。北墙是普通的橡木门。地板上有些可疑的暗色污渍（#3a2a1a 干涸液体痕迹）。墙角有一口熄灭的坩埚（#444444）。

## 6. library — 古旧图书馆

```
房间职能：知识枢纽，可触发魔法饼干随机出现
出口：西(theatre) / 北(hidden-shrine) / 东(teleport-alcove)
物品：ancient-tome（一本古书），放在倒下的书架上
NPC：无（但隐士在 hidden-shrine 中）
```

**布局描述**：
一座布满灰尘的古老图书馆，约 30×16 格。三面墙壁（北、南、西）都是高耸的书架——深色橡木框架（#5a3a2a），每个书架 5 格高，塞满了破旧的书脊（#8a3a3a 红 / #3a5a8a 蓝 / #6a6a3a 绿）。北墙的书架中央有一个隐藏式旋转暗门（通向 hidden-shrine）——门缝几乎不可见（#4a4a4a，比墙壁稍亮一条细线）。房间中央有一个翻倒的书架，旁边散落着几本掉落的书。其中最显眼的是一本厚重的皮革装订大书（ancient-tome，#6a3a1a 深棕皮面，6×8 格），封面有模糊的金色符文（#c0a030），这是商人愿意高价收购的珍品。东墙拱门通向传送密室——拱门周围有微弱的魔法光晕（#4488cc 淡蓝，2 格宽）。火把只有两支，大部分区域笼罩在阴影中。地板上铺着一条破旧的暗红色地毯（#5a2a2a）。

## 7. cellar — 阴暗地窖

```
房间职能：低层储物间，可触发魔法饼干
出口：北(pub)
物品：old-barrel（一个腐烂的大木桶），在房间角落
```

**布局描述**：

## 8. vault — 上锁宝库

```
房间职能：锁门奖励房间（需要 key-vault 打开 vault-door）
出口：北(lab)（入口即上锁的 vault-door）
物品：gem-light（光之宝石）+ gold-coins（金币堆），放在宝库中央
```

**布局描述**：
一间被沉重铁门封锁的宝库，约 30×16 格。北墙是一扇巨大的铁门（vault-door，#808090 厚重铁门，占 6×10 格）——门上有一个显眼的钥匙孔（#404040）和装饰性铆钉（#909090）。一旦用 key-vault 打开，铁门会缓缓开启。宝库内部四壁是抛光的深色石材（#3a3a4a），比外面更加精致。房间正中央有一个石制基座（#5a5a5a，4×4 格），上面放置着两件宝物：一颗散发着柔和白光的宝石（gem-light，#e8e0d0 白金色，4×4 格，周围有 2 格半径的微光光晕 #ffe8c0）和一小堆散落的金币（gold-coins，#c0a030 金色，不规则堆叠，约 3×5 格）。基座旁还有几个空宝箱（#8a6a3a），盖子半开。火把插在东西两墙，反射在抛光石面上形成暖色光斑。

## 9. hidden-shrine — 隐士神龛

```
房间职能：隐士 NPC 所在地，可触发魔法饼干
出口：南(library)（通过隐藏暗门）
物品：crystal-shard（水晶碎片），放在祭坛上
NPC：hermit（隐士，蓝色色块）
```

**布局描述**：
隐藏在图书馆书架后的秘密神龛，约 30×16 格。入口是南墙的一道伪装的旋转石门——从外面看是书架的一部分，从里面可以看到石门的轮廓。神龛内部是一个小型礼拜堂——北墙有一座石制祭坛（#5a5a5a，6×4 格，带三级台阶），祭坛上放着一块微微发光的水晶碎片（crystal-shard，#88ccff 淡蓝色透明，3×3 格，发出微弱的蓝色光晕）。房间东西两面墙壁上有褪色的壁画（#4a4a6a 暗蓝底色，描绘模糊的王国历史场景）。隐士（hermit）通常站在祭坛右侧——一个穿着暗蓝斗篷的身影（#4488cc 蓝色色块，12×16 格占位），手持木杖。火把是蓝色的魔法火焰（#4488cc），给整个房间蒙上神秘的蓝色调。地板上有宗教仪式用的几何图案刻痕（#3a3a4a）。

## 10. garden — 宁静庭院

```
房间职能：NPC 守卫外围 + 连接枢纽
出口：西(pub) / 南(guard-room)（南门上锁） / 东(armory)
物品：healing-herb（一株草药），长在花坛中
NPC：guard（守卫，在 guard-room 门外，红蓝双色块，位置取决于门锁状态）
```

**布局描述**：
一个被古老石墙环绕的露天庭院，约 30×16 格。天空可见——上方是深蓝紫色夜空（#202040），有几颗星星（#ffffff 白点）。庭院中央有一个小型石砌喷泉（#5a5a5a，6×6 格），喷泉已干涸，底部有几片枯叶（#6a5a2a）。东侧有一个杂草丛生的花坛——在杂草（#4a6a2a）中间，长着一株发光的草药（healing-herb，#44cc44 翠绿色，4×5 格，有淡绿色微光）。南墙是一扇巨大的铁栅栏门（guard-gate，#808090），通往 guard-room——门外站着手持长矛的王座守卫（guard，#cc4444 红色色块，14×16 格，若已在里面则不出现）。西墙拱门通向 pub。东墙拱门通向 armory。地板是石板和杂草混合。四角有火把，但庭院上方有月光（#6688aa 淡蓝月光）补充照明。

## 11. guard-room — 守卫哨站

```
房间职能：守卫 NPC 内间（guard-gate 上锁，需对话或钥匙或杀守卫后进入）
出口：北(garden) / 南(throne-hall)
NPC：guard（守卫，红色色块，位于房间内）
```

**布局描述**：
守卫的值班哨站，约 30×16 格。北墙是铁栅栏门（guard-gate）——从 garden 进入。房间是简单的军事哨所：西墙有一张简陋的木床（#5a3a2a，8×6 格）和一个小木桌（#6a4a2a），桌上放着一盏油灯（#e8a030）。东墙挂着武器架——上面插着一把备用长矛（#888888 铁头 + #6a4a2a 木柄）。守卫（guard）通常站在房间中央或南门附近——一个身穿暗红铠甲的高大身影（#cc4444 红色色块，16×16 格），手持长矛。南墙是一扇厚重的橡木门——门框上方刻有王座的浮雕。地板是磨损的石板，守卫经常站立的位置有明显磨痕（#5a5a5a）。气氛威严而紧张。墙上有两支火把。

## 12. armory — 军械库

```
房间职能：装备获取
出口：西(garden) / 南(forge)
物品：sword-rusty（生锈长剑）+ shield-wooden（木盾），放在武器架上
```

**布局描述**：
城堡的旧军械仓库，约 30×16 格。三面墙壁（北、南、东）排列着木制武器架（#5a3a2a，2 格高）。北墙的武器架上横放着一把布满锈迹的长剑（sword-rusty，#8a6a4a 金属锈色，刃长 12 格，剑柄缠着褪色的皮革 #5a3a2a）——虽然陈旧但剑刃仍泛着微光。旁边立着一面略有破损的橡木圆盾（shield-wooden，#7a5a3a 木质，直径 10 格，边缘有铁质包边 #808080，正面有褪色的王国纹章）。东墙的武器架大多是空的，只剩几支断箭（#6a4a2a）。南墙拱门通向 forge——拱门另一侧可以看到锻造炉的暖橙色光芒。地板上散落着一些生锈的铁片和碎木屑（#5a4a3a）。房间只有一支火把——大部分区域在阴影中。空气中弥漫着陈旧的金属气味。

## 13. forge — 炽热铁匠铺

```
房间职能：商人 NPC 所在地
出口：北(armory)
NPC：merchant（商人/铁匠，金色色块）
```

**布局描述**：
一间仍在运作的锻造工坊，约 30×16 格。房间中央是一座熊熊燃烧的铸造炉（#e84020 橙红火焰，6×6 格）——火焰跳动，照亮了整个房间（橙色光晕半径 6 格，最强光源）。铸造炉旁有一个大铁砧（#606060 深铁色，4×3 格），旁边放着一把锻造锤（#808080）。北墙是通往 armory 的拱门。南墙有一排完工和半完工的武器陈列在墙上——剑、斧、盾的轮廓（#808080 铁色）。商人/铁匠（merchant）站在铸造炉左侧——一个围着皮围裙的矮壮身影（#ccaa22 金色色块，14×16 格），似乎在等待顾客。西墙有一张交易桌（#6a4a2a）——上面放着几件待售的小物件（#888888 铁片）。整个房间被炉火映照成暖橙色（#4a3a2a 暖色调地板反光）。天花板有通风口——可以看到火星飘上（#e8a030 小光点）。

## 14. teleport-alcove — 传送密室

```
房间职能：随机传送至其他房间
出口：西(library)（单向：由于传送属性，入口不会直接返回）
物品：warp-dust（传送粉尘），散落在地板上
```

**布局描述**：
一间充满不稳定魔法能量的密室，约 30×16 格。西墙是拱门（通向 library）。房间中央地面上刻着一个魔法传送阵——一个发光的圆形符文圈（#4488cc 蓝光，直径 12 格），符文线条不断闪烁扭曲（#88ccff 亮蓝）。传送阵边缘散落着细碎的发光粉尘（warp-dust，#aaccff 淡蓝紫色，不规则散布，约 5×3 格区域）——这些粉尘微微悬浮在空中。四壁是古老的光滑黑石（#2a2a3a），上面刻满了密密麻麻的符文（#4466aa 暗蓝），符文偶尔会短暂发光然后熄灭。天花板很高——可以看到魔法能量向上蒸腾（#4488cc 半透明蓝光柱）。房间没有火把——唯一的照明来自传送阵本身的蓝色冷光。踏入传送阵的玩家会在 1-2 秒后随机传送到另一个房间。墙壁偶尔发出低沉的嗡鸣声。

## 15. throne-hall — 王座大厅

```
房间职能：结局判定房间
出口：北(guard-room)（唯一入口）
物品：无
NPC：无（但结局评估引擎在此触发）
```

**布局描述**：
游戏中最宏伟的房间——失落王国的王座大厅，约 30×16 格。北墙是厚重的橡木大门（入口），门框上方刻着王冠浮雕（#c0a030 金色）。房间是狭长的矩形——从北门向南方延伸。两侧各有六根粗大的石柱（#4a4a4a，3 格宽 × 12 格高），柱身有螺旋状雕刻（#5a5a5a）。每条柱子上都插着一支燃烧的火把——共 12 支，将大厅照亮成庄严的暖橙色。地板是中轴线式的深红地毯（#6a1a1a），从北门一直铺到王座下方。南墙尽头是一个石制高台（5 级台阶，#555555 → #6a6a6a），台座之上是一张巨大的石制王座（#5a5a5a，8×10 格）——王座靠背极高，顶端嵌着一颗巨大的暗色宝石（当前无光）。大厅天花板是拱形的——高处的彩色玻璃窗（#4466aa 蓝 / #aa4444 红 / #aaaa44 金，碎片拼接）投下斑斓的光线。当玩家踏入大厅时，结局评估触发——根据玩家的选择，王座上的宝石会呈现不同颜色：光明结局（#e8e0d0 白光）、暗影结局（#cc2222 血红）、中立结局（#888888 灰暗）。
