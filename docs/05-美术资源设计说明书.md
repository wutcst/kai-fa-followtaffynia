## 2. 视觉风格定位

### 2.1 整体方向

| 维度 | 约定 |
|------|------|
| 类型 | 俯视角 2D 像素 RPG（房间制探索） |
| 时代感 | 16-bit 复古（SNES / GBA 档次），**非**高清手绘 |
| 视角 | 正交俯视，无透视变形 |
| 比例 | 角色约 **1 格高**（32px），门、树等 1–2 格 |
| 氛围 | 「失落 Realm」：偏暗的石室、暖色酒馆、冷色图书馆、金库神秘光 |

### 2.2 画面原则

1. **像素清晰**：放大窗口时使用最近邻，禁止模糊拉伸（代码侧 `Nearest`，美术侧导出 PNG 不抗锯齿）。  
2. **对比可读**：地面与墙、可行走区与碰撞区在缩略图里也能区分。  
3. **互动可辨**：地面物品、NPC 与装饰物轮廓清晰，便于 `E` 提示对齐。  
4. **UI 不抢戏**：对话框、HUD 使用深色半透明底 + 浅色字，不遮挡战斗/谜题关键区域。

### 2.3 参考气质（非照搬）

- 早期《塞尔达》房间制地牢  
- 《星露谷物语》室内像素密度（仅作密度参考）  
- 开源包 **Tiny RPG / Kenney Roguelike** 的配色克制感

## 5. 图块集（Tileset）设计

### 5.1 规格

| 项 | 值 |
|----|-----|
| 单格尺寸 | **32×32 px** |
| 间距/边距 | 0（紧密排列，LibGDX 默认） |
| 格式 | PNG-24 或 PNG-8（索引色更省体积） |

### 5.2 最少图块清单（主 tileset 建议 ≥40 格）

| 类别 | 数量建议 | 说明 |
|------|----------|------|
| 草地/石板 | 4–6 | 可随机变体防重复感 |
| 墙体（上/下/角/柱） | 8–12 | 用于 `wall` 碰撞层 |
| 门（关/开） | 2–4 | 与 `lockId` 联动换 gid |
| 水/坑（不可走） | 2 | 装饰或阻挡 |
| 地毯/木 floor | 4 | 室内 |
| 装饰（桌、椅、书架、火把） | 10+ | 放 `decor` 层，无碰撞 |
| 出口标记（可选） | 1 | 开发期可见，发布可隐藏 |

### 5.3 Tiled 图层用法（与程序一致）

| 图层 | 美术注意 |
|------|----------|
| `ground` | 可行走地面，铺满无洞 |
| `wall` | **所有不可通行处** 必须有墙格（程序读此层做碰撞） |
| `decor` | 纯视觉，不挡路；大树等需脚下留出一格通道 |
| `objects` | 不画像素也行，用矩形/点对象标 spawn、exit、item、npc |

### 5.4 门与谜题表现

| 状态 | 表现 |
|------|------|
| 门锁定 | 关门的墙格 + 门图块；碰撞开启 |
| 门解锁 | 换「开门」gid 或移除 `wall` 一格 | 
| 火把点燃 | decor 层火把帧 1→2；可配暖色光晕贴图 |
| 壁龛 | 空龛 → 有宝石，用 decor 两帧切换 |

## 6. 角色与实体精灵

### 6.1 玩家 `player.png`

```
布局：4 行 × 4 列，每帧 32×32
行序：down → left → right → up（与 04 §7.1 一致）
列序：idle | walk1 | walk2 | walk3
```

| 项 | 约定 |
|----|------|
| 动画帧率 | 8 FPS（代码 125ms/帧） |
| 默认朝向 | down（面向镜头） |
| 剪影 | 头部+身体轮廓明显，与地面色对比强 |
| 占位阶段 | 纯色 16×16 居中于 32×32 透明底 |

### 6.2 NPC `npc-<npcId>.png`

| npcId | 角色定位 | 外形提示 |
|-------|----------|----------|
| guard | 守卫 | 盔甲、矛或盾 |
| merchant | 商人（forge） | 围裙、背包 |
| hermit | 隐士（hidden-shrine） | 斗篷、杖 |

- 布局：**1 行 × 4 列** idle 循环，或单帧站立。  
- 同屏 NPC 高度与玩家一致，避免比例失调。

### 6.3 物品图标 `items.png`

| 要求 | 说明 |
|------|------|
| 尺寸 | 16×16 或 32×32 统一一种 |
| 排列 | 网格表，manifest 登记 `(itemId → col,row)` |
| 必画 id | 见下表 |

| itemId（示例） | 外形 |
|----------------|------|
| magic-cookie | 发光饼干 |
| key-vault | 生锈金钥匙 |
| key-guard | 铁钥匙 |
| torch | 火把 |
| gem-light | 光明宝石（剧情） |
| sword-rusty | 锈剑（重） |

地图上可只显示小图标；背包 UI 放大同一图标。

## 7. UI 美术

### 7.1 组件清单

| 资源 | 用途 | 规格建议 |
|------|------|----------|
| `dialogue-box.9.png` | 对话框 | 九宫格，边框 8px，可拉伸 |
| `hud-panel.9.png` | HP/声望底 | 左上角，宽 120–200px |
| `button.png` | 标题/暂停菜单 | 三态：normal / hover / pressed（可选） |
| `icon-interact-e.png` | 互动提示 | 16×16 或 24×24，黄底白字 E |
| `icon-hp.png` / `icon-reputation.png` | HUD 图标 | 16×16 |
| `pixel-main.fnt` | 中文+英文 | 建议 12–16px 字高；可用 Hiero 生成 |

### 7.2 布局示意（960×540）

```
┌─────────────────────────────────────────────┐
│ [HP████] [声望☆]              [小地图 80×80] │
│                                             │
│              （游戏画面 30×17 格）           │
│                    [E] ← 浮动于实体头顶      │
│                                             │
│ ┌─────────────────────────────────────────┐ │
│ │ 对话框：NPC 名 + 正文 + [选项1] [选项2]   │ │
│ └─────────────────────────────────────────┘ │
└─────────────────────────────────────────────┘
```

### 7.3 字体

- 中文：优先 **思源黑体** 或 **方舟像素字体** 等可商用字体，经 Hiero 打成 `fnt`。  
- 英文/数字：与中文同字体，保持像素对齐。  
- 禁止：系统宋体直接拉伸（会破坏像素感）。

## 8. 制作流程（成员 A）

### 8.1 三阶段策略（推荐）

| 阶段 | 时间 | 美术目标 | 程序对接 |
|------|------|----------|----------|
| **P0 占位** | 第 1 周 | 4 色 tileset + 色块 player + 无 UI 图 | C 用 ShapeRenderer/纯色通过 |
| **P1 可玩** | 第 2–3 周 | 主 tileset + 5 张完整 tmx + 玩家行走图 | 全功能联调 |
| **P2 抛光** | 第 4–5 周 | 15 房、3 NPC、UI 九宫格、物品图标 | 替换占位，统一 palette |

**原则**：逻辑开发不等待最终美术；**先规格对齐、后换皮**。

### 8.2 Tiled 工作流

1. 用 `realm-tiles.tsx` 新建 `<roomId>.tmx`，地图大小建议 **30×17 格**（与窗口可视区一致）或更大+相机裁剪。  
2. 画 `ground` → `wall` → `decor` → 放置 `objects`。  
3. 导出 **XML (.tmx)**，相对路径引用 tileset。  
4. 提交前在 Tiled 检查：**无孤立墙洞、spawn 在可行走格上**。  

### 8.3 占位资源（第 1 周即可用）

| 资源 | 占位做法 |
|------|----------|
| tileset | 32×32 纯色块：绿地面、灰墙、棕门 |
| player | 蓝方块 16×16 |
| NPC | 红/黄/紫方块 |
| UI | LibGDX 默认 `skin` 或纯色矩形 + 系统字体 |

占位图放 `assets/placeholder/`，manifest 中 `usePlaceholder=true` 时由 `AssetCatalog` 切换路径（实现期约定）。

### 9.1 推荐来源（需保留出处）

| 来源 | 许可 | 适用 |
|------|------|------|
| [Kenney.nl](https://kenney.nl/assets) | CC0 | 图块、UI、角色 |
| [OpenGameArt](https://opengameart.org/) | 各作者许可 | RPG 像素包 |
| [itch.io](https://itch.io/game-assets/free/tag-pixel-art) | 看具体包 | 完整 tileset |
| Liberated Pixel Cup / 0x72 | CC-BY / CC0 | 地牢图块 |

### 9.2 使用规范

1. 下载后统一 **缩放至 32×32**（最近邻），勿平滑。  
2. 在 `assets/CREDITS.md` 记录：包名、作者、许可证、URL。  
3. 实验报告与 **README** 各写一节「美术资源出处」。  
4. 若用 AI 生成贴图：注明模型与人工修改范围（满足课设 AI 披露要求）。

### 9.3 禁止

- 无授权的商业游戏截图拼贴  
- 带水印预览图直接入库  
- 混用多种不兼容像素比例（16px 人与 32px 墙强行拼）
