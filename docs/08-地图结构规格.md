# 地图结构规格 —— TMX 重制参考

> **用途**：从零重制 15 张 TMX 地图时的结构参考。只描述"接口层"（出口、出生点、特殊对象），不约束瓦片细节。
>
> **代码权威来源**：`WorldFactory.java`（拓扑） + `RoomScene.java`（spawn 匹配规则）。

---

## 1. 全局规格

| 参数 | 值 |
|------|-----|
| 地图尺寸 | **30 格 × 17 格** |
| 瓦片大小 | **32 × 32 px** |
| 图块集 | `../tilesets/tiny-dungeon.tsx` |
| 图层顺序 | `ground` → `wall` → `decor` → `objects` |

### 图层说明

| 图层 | 类型 | 说明 |
|------|------|------|
| `ground` | 瓦片层 | 地板，纯视觉 |
| `wall` | 瓦片层 | 墙壁/碰撞——**任何非零格子 = 阻挡** |
| `decor` | 瓦片层 | 装饰物，纯视觉，无碰撞 |
| `objects` | 对象层 | 交互对象（见下方） |

### objects 层对象规范

- **形状**：32×32 矩形
- **type** 字段：`spawn` / `exit` / `door` / `trigger`
- **属性**：见各对象类型说明

## 2. Spawn 与 Exit 匹配规则（重要）

```
玩家从房间 X 的 "北侧" 进入 → entryDirection = NORTH
→ 房间内使用 direction=south 的 spawn（出现在房间南侧/底部）
```

| 进入方向（entryDirection） | 使用的 spawn direction | spawn 在地图上的位置 |
|--------------------------|----------------------|-------------------|
| NORTH | south | 地图**下**方（底部） |
| SOUTH | north | 地图**上**方（顶部） |
| EAST | west | 地图**左**方 |
| WEST | east | 地图**右**方 |
| DEFAULT | default | 地图**中央** |

**记忆口诀**：spawn 放在"进来的对侧"。

## 6. 你的制作清单

为每张地图，你需要完成以下工作：

1. **ground 层**：地板瓦片（自由发挥）
2. **wall 层**：墙壁瓦片——**确保出口处留空**（exit 区域及其前方 1~2 格不得有墙）
3. **decor 层**：装饰（自由发挥）
4. **objects 层**：按 §4 表格放置 spawn / exit / door 对象

### 制作顺序建议

先做 **outside**（中心房间，4 出口 5 spawn），做一张测试通过后再批量做其余 14 张。

做完每张后，在 Tiled 中检查：
- 出口处 wall 层为空（玩家能走到 exit 对象上）
- spawn 点处 wall 层为空（玩家不会卡在墙里）
- exit 的 `targetRoomId` 拼写与目标房间的 roomId **完全一致**（全小写，连字符）
