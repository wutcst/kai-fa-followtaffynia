## 二、世界构建（WorldFactory）

### 2.1 15 房间完整拓扑

按 `docs/04-roomId规范与接口约定.md` §3.1 实现全部 15 间房的注册和双向出口连接：

```
outside  N→theatre, E→pub, S→lab, W→office
theatre  S→outside, E→library
pub      W→outside, S→cellar
lab      N→outside, E→vault
office   E→outside
library  W→theatre, N→hidden-shrine, E→teleport-alcove
cellar   N→pub
vault    W→lab
hidden-shrine  S→library
garden   N→outside, S→guard-room
guard-room     N→garden, S→throne-hall, W→armory
armory   E→guard-room, S→forge
forge    N→armory
teleport-alcove  W→library
```

### 2.2 房间特殊属性

| 房间 | 属性 | 说明 |

| `guard-room` | `lockId=guard-gate` | 需 `key-guard` 解锁 |

## 五、引擎增强（GameEngine）

### 5.1 门锁系统

- `movePlayer()` 检查目标房间 `lockId`，未解锁时拒绝进入并记录日志
- `useItem()` 返回 `String`（之前返回 `boolean`），支持效果执行：

| 效果键 | 格式 | 行为 |
|--------|------|------|
| `unlock` | `unlock:<lockId>` | 解锁指定门，消耗物品 |
| `heal` | `heal:<amount>` | 恢复 HP，消耗物品 |
| `light` | `light` | 光照效果，消耗物品 |
| `reputation` | `reputation:<delta>` | 调整声望，消耗物品 |

### 5.2 谜题链

**金库谜题**：lab(拿 key-vault) → vault(锁) → 使用钥匙 → vault(进入) → 拿 gem-light + gold-coins

**守卫谜题**：office(拿 key-guard) → guard-room(锁) → 使用钥匙 → guard-room(进入) → throne-hall(结局)
