 1. 光明结局（EndingType.LIGHT）

  "你携光明宝石步入王座大厅，Realm 的记忆被重新点亮。"

  触发条件（EndingEvaluator.java 中全部条件必须满足）：
  - 持有 光明印记（light-mark）—— 在 theatre 击败 priest 获得
  - 持有 光之宝石（gem-light）—— 在 vault 房间拾取（需先获取金库钥匙，打败 golem）
  - 持有 守卫勋章（guard-medal）—— 在 armory 击败 apprentice 获得
  - 声望 >= 0
  - 未击杀 Guard（守卫）和 Hermit（隐士）

  流程：与 theatre 的 priest 对话 → 接受试炼并击败他 → 获得光明印记 → 拿到金库钥匙 → 打开 vault → 击败 golem →
  拾取光之宝石 → 击败 apprentice 获得守卫勋章 → 通过守卫 → 进入 throne-hall → 触碰王座。

  ---
  2. 暗影结局（EndingType.SHADOW）

  "暗影吞噬了王座，编年史者在沉默中离去。"

  触发条件：
  - 持有 暗影之契（shadow-pact）—— 在 cellar 击败 follower 获得
  - 满足其一：击杀了 Guard（守卫）或 声望 < 0

  流程：与 cellar 的 follower 对话 → 接受试炼并击败他 → 获得暗影之契 → 击杀守卫（或声望为负硬闯）→ 进入 throne-hall →
  触碰王座。

  ---
  3. 中立结局（EndingType.NEUTRAL）

  "你触碰了王座，却知晓它不属于你。你已走过光明与暗影的两端，了解 Realm
  的一切。你选择等待——等待那最终之人成为永恒的王，而你，将以编年史者之名，辅佐左右。"

  触发条件：
  - 持有 平衡之书（balance-book）—— 同时拒绝 priest 和 follower 后，与 library 的 scholar（学者）对话获得
  - 持有 守卫勋章（guard-medal）—— 击败 apprentice 获得
  - 已设置 refused-priest 标志（在 priest 对话中选择拒绝）
  - 已设置 refused-follower 标志（在 follower 对话中选择拒绝）
  - 声望 >= 0
  - 未击杀 Guard 和 Hermit

  流程：与 priest 对话选拒绝 → 与 follower 对话选拒绝 → 两个拒绝标志都集齐后，找 library 的 scholar → 获得平衡之书 →
  击败 apprentice 获得守卫勋章 → 守卫会友好放行（guard_neutral 对话）→ 进入 throne-hall → 触碰王座。

  ---
  第四种：虚结局（EndingType.FAKE，非正典）

  "似蜉蝣于天地，如沧海之一粟。王座没有任何回应。你没有留下任何痕迹，没有人记得你来过。"

  当玩家以上三种结局的条件都不满足时，触碰王座就会触发这个结局——相当于"你来过了，但什么都没改变"。

  ---
  死亡（Game Over，非结局）

  HP 归零时触发，显示心碎图案和"你倒下了"，可按 F9/L 读档或 T 返回标题。
