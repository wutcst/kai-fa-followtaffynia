# 过场动画设计文档

> 模仿 Elden Ring 结局演出风格。供 UI/动画组成员实施。

---

## §1 整体结构

触发时机：玩家在王座大厅走到王座前按 E → `tryTriggerEnding()` 判定结局 → 进入过场动画

动画流程分 **五个阶段**：

| 阶段 | 时长 | 内容 |
|------|------|------|
| 1. 淡入黑幕 | 1.0s | 全屏渐黑，游戏画面淡出 |
| 2. 图片序列（左→右）| 每张 1.5s | 2~3 张关键剧情图片从左向右滑入 |
| 3. 图片（上→下）| 1.5s | 1 张图片从上向下滑入 |
| 4. 图片（下→上）| 2.0s | 主角坐王座的最终图从下向上滑入 |
| 5. 文字演出 | 3.0s 打字 + 停留 | 结局文字逐行显现，「落叶传来讯息」收尾 |
| 6. 按 T 返回标题 | 等待 | 底部提示「按 T 返回标题」 |

## §3 结局文字

### 3.1 光明结局 — 众星拱月

```
落叶传来讯息——

光之宝石在王座上绽放，
失落 Realm 的每一块砖石都被重新点亮。
守卫放下了长矛，隐士走出了神龛，
那些曾在暗影中徘徊的灵魂，
第一次看见了彼此的面容。

诸星归位，辉光重铸。
编年史者没有成为国王——
她成为了光本身。

这是一个众星拱月的时代。
```

### 3.2 暗影结局 — 步入深渊

```
落叶传来讯息——

王座在暗影之契的力量下碎裂，
守卫的血染红了通往王座的地毯，
隐士的预言在火焰中化为灰烬。
编年史者坐上了王座——
但她的眼中，只剩下深渊的回响。

万物归暗，诸火寂灭。
Realm 没有拯救者——
它只有了新的主人。

这是一个步入深渊的时代。
```

### 3.3 中立结局 — 无为暗淡

```
落叶传来讯息——

在远古的黄金树下，失落 Realm 的王座前，
编年史者静默伫立。
她没有带来光明，也没有投身暗影，
只是走过了每一间密室，拾起了每一片残页，
然后——什么也没有改变。

王座依旧冰冷，Realm 依旧破碎，
而编年史者的名字，
在时间的长河中渐渐褪去。

这是一个无为暗淡的时代。
```

## §4 动画时序

```
t=0.0s   阶段1开始：全屏黑幕从 0% 透明度渐变到 100%，持续 1.0s
t=1.0s   阶段2开始：图片1（light_01/shadow_01/neutral_01）
             从屏幕左侧外 (-宽度, 居中) 滑入到 (0, 居中)，持续 1.5s
             缓动：ease-out cubic
t=2.5s   图片2（light_02/shadow_02/neutral_02）
             同上动画，覆盖图片1
t=4.0s   阶段3开始：图片从屏幕上方外 (居中, -高度) 滑入到 (居中, 居中)
             持续 1.5s，同一张图片或第三张图
t=5.5s   阶段4开始：终图（*_final.png）从屏幕下方外 (居中, 屏幕高度)
             滑入到 (居中, 60%屏幕高度)，持续 2.0s
             缓动：ease-out quint
t=7.5s   阶段5开始：文字逐行淡入
             每行 0.5s 间隔，从第一行到最后一行
             最后一行停留 1.0s
t=10.5s  阶段6：「按 T 返回标题」提示淡入
             等待玩家按 T
```

## §5 技术实现建议

### 5.1 现有代码入口

`GameScreen.render()` 中检测 `engine.getCurrentEnding()` 非空时进入结局模式。目前的 `drawEndingScreen()` 方法可替换或扩展为完整过场动画。

### 5.2 建议新增类

```java
// 新建文件：src/.../client/screen/EndingCutscene.java
public class EndingCutscene {
    private EndingType ending;
    private float elapsed;
    private int stage;  // 0-5

    public void update(float delta) { ... }
    public void render(SpriteBatch batch, ShapeRenderer shapes, ...) { ... }
    public boolean isFinished() { ... }
}
```

### 5.3 图片加载

使用 LibGDX `Texture` 加载，路径根据结局类型动态拼接：

```java
String prefix = "assets/ending/" + ending.name().toLowerCase();
Texture img1 = new Texture(prefix + "_01.png");
Texture img2 = new Texture(prefix + "_02.png");
Texture imgFinal = new Texture(prefix + "_final.png");
```

### 5.4 文字渲染

使用现有 `BitmapFont`，`font.draw()` 的 `wrap` 参数支持 `\n` 换行。逐行 alpha 从 0 渐变到 1。

### 5.5 缓动函数

```java
// ease-out cubic
float t = Math.min(1f, elapsed / duration);
return 1f - (1f - t) * (1f - t) * (1f - t);

// ease-out quint
return 1f - (1f - t) * (1f - t) * (1f - t) * (1f - t) * (1f - t);
```
