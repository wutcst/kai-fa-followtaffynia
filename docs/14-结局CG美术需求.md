## 🌟 光明结局 — 光辉重燃

**触发**：光明印记 + 光之宝石 + 守卫勋章，王座前按E

**画面分镜**：
1. 王座大厅背景（thronehall.jpg）亮度从暗→亮，金色光晕从王座向外扩散
2. 光之宝石从背包中升起，浮在王座上方，旋转发光
3. 金色粒子（光点）从四周汇聚到王座
4. 文字渐显：「你携光明宝石步入王座大厅，Realm 的记忆被重新点亮。」

**色调**：暖金色（#FFD700 / #FFA500），背景亮度提升 40%

**音效**：光明主题 BGM（建议 `assets/audio/bgm/light-ending.ogg`）

---

## 🌑 暗影结局 — 深渊加冕

**触发**：暗影之契 + 杀守卫，王座前按E

**画面分镜**：
1. 王座大厅背景逐渐被暗红色滤镜覆盖
2. 暗影之契从背包中升起，在王座上方展开如黑色火焰
3. 暗影粒子从王座下方上涌，吞噬画面边缘
4. 文字渐显：「暗影吞噬了王座，编年史者在沉默中离去。」

**色调**：暗红+黑（#8B0000 / #1a0000），红色滤镜 opacity 60%

**音效**：暗影主题 BGM（建议 `assets/audio/bgm/shadow-ending.ogg`）

## ⚖️ 中立结局 — 等待之王 ★ NEW

**触发**：平衡之书 + 守卫勋章，王座前按E

**画面分镜**：
1. 王座大厅背景保持自然色调，不急不缓
2. 主角走向王座 → 伸出手 → **在碰到王座前收回手**
3. 平衡之书在主角胸前展开，散发柔和的灰金色光芒
4. 画面拉远，主角转身背对王座，面向镜头（即面向入口方向）
5. 王座在背景中保持空置，但不再冰冷——有微光从窗外洒在王座上
6. 文字逐行渐显：

```
你触碰了王座，却知晓它不属于你。
你已走过光明与暗影的两端，了解 Realm 的一切。
你选择等待——等待那最终之人成为永恒的王，
而你，将以编年史者之名，辅佐左右。
```

**色调**：灰金色（#C0A060 / #8B7D6B），不暗不亮，庄重柔和

**粒子**：缓慢飘落的金色书页碎片（非落叶，是编年史的书页）

**音效**：中立主题 BGM（建议 `assets/audio/bgm/neutral-ending.ogg`），比光明/暗影更安静、悠长

**关键设计点**：
- 主角伸手→收手这个动作是核心——表示「我能拿，但我不拿」
- 王座不能看起来被废弃或毁坏，而是**在等待**——光洒在王座上暗示它终将被坐
- 主角转身背对王座，表示「我不坐在上面，我守卫它」
