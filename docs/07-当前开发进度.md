## 三、结局路线详解

进入 `throne-hall` 时 `EndingEvaluator` 判定，条件：

```
LIGHT:  有 gem-light AND 声望 >= 0 AND 守卫未死 AND 隐士未死
SHADOW: 声望 < 0 OR 隐士被杀 OR (守卫被杀 AND 无 gem-light)
NEUTRAL: 其余所有情况
```

### 3.1 光明结局 LIGHT

1. `outside` → 南 → `lab` → 东 → `vault`（需 `key-vault`）
2. 在 vault 拾取 `gem-light`（5 重量）
3. 返回 `outside` → 东 → `pub` → 东 → `garden`
4. 在 garden 南门遇到守卫 → 按 E → 按 1 交流 → 选 1「我是编年史者」
5. 守卫开门（`guard-gate` 解锁），进入 `guard-room` → 南 → `throne-hall`
6. 结局判定：有 gem ✅ / 声望 ≥0 ✅ / 无人死亡 ✅ → **LIGHT**

### 3.2 暗影结局 SHADOW（三种达成方式）

**方式 A**：杀守卫 → 声望变 -15 → **SHADOW**

**方式 B**：杀隐士 → `hermitDead` → **SHADOW**

**方式 C**：杀守卫 + 不拿 gem-light → **SHADOW**

### 3.3 中立结局 NEUTRAL

不拿 gem-light + 不杀人 + 进入 throne-hall → **NEUTRAL**

验证测试：`EndingFlowTest` 5 个完整流程测试全部通过。

## 六、Undertale 战斗系统

```
CombatSystem 接口
  └── UndertaleCombatEngine（UT 弹幕式）
       ├── 五阶段：MENU → FIGHT_BAR → ENEMY_TURN → RESULT
       ├── 菜单：1=FIGHT 2=ACT 3=ITEM 4=MERCY
       │    ├── FIGHT → 节奏攻击条（中心区域按 Enter 伤害最高）
       │    ├── ACT → 调查/交谈/威吓（JSON 配置 actOptions）
       │    ├── ITEM → 使用背包物品
       │    └── MERCY → 双连退出（1次嘲讽 + 敌人回合 → 2次和解结束）
       ├── Bullet — 弹幕实体（圆形/矩形 + AABB碰撞）
       ├── BulletPattern — 4 种图案（wave/burst/scatter/spiral）
       ├── BattleLine — 战斗台词系统（start/hp50/hp10/mercy1/mercy2）
       │    └── 底部画中画 Overlay + Enter 继续 + phaseAfterBattleLine 流转
       └── UtCombatRenderer — 弹幕/灵魂/节奏条/HP条/按钮完整渲染
```

**游戏中调用**：按 E 遇 NPC → 按 2 → `engine.startCombat(npcId, CombatMode.UNDERTALE)`

**战斗数据**：`assets/combat/guard.json` + `hermit.json`，含 HP、技能、actOptions、battleLines

**引擎 + 渲染均由 B 完成**，不在待办列表。
