## 三、结局路线详解

进入 `throne-hall` 时 `EndingEvaluator` 判定，条件：

```
LIGHT:  有 gem-light AND 声望 >= 0 AND 守卫未死 AND 隐士未死
SHADOW: 声望 < 0 OR 隐士被杀 OR (守卫被杀 AND 无 gem-light)
NEUTRAL: 其余所有情况
```

### 3.1 光明结局 LIGHT

**步骤：**

1. `outside` → 南 → `lab` → 东 → `vault`（需 `key-vault`）
2. 在 vault 拾取 `gem-light`（5 重量）
3. 返回 `outside` → 东 → `pub` → 东 → `garden`
4. 在 garden 南门遇到守卫 → 按 E → 按 1 交流 → 选 1「我是编年史者」
5. 守卫开门（`guard-gate` 解锁），进入 `guard-room` → 南 → `throne-hall`
6. 结局判定：有 gem ✅ / 声望 ≥0 ✅ / 无人死亡 ✅ → **LIGHT**

**验证测试**：`EndingFlowTest.lightEnding_fullFlow`

### 3.2 暗影结局 SHADOW（三种达成方式）

#### 方式 A：杀守卫（声望为负）

1. `outside` → 东 → `pub` → 东 → `garden`
2. 遇到守卫 → 按 E → 按 2 杀害 → 回合制战斗 → 杀死守卫
3. 声望变 -15，守卫加入 `defeatedNpcs`
4. 门自动破开 → 进入 `guard-room` → 南 → `throne-hall`
5. 结局判定：声望 -15 < 0 → **SHADOW**

**验证测试**：`EndingFlowTest.shadowEnding_killGuard`

#### 方式 B：杀隐士

1. `outside` → 北 → `theatre` → 东 → `library` → 北 → `hidden-shrine`
2. 遇到隐士 → 按 E → 按 2 杀害 → 战斗 → 杀死隐士
3. 隐士加入 `defeatedNpcs`
4. 返回 `outside` → 去 `throne-hall`（需先解锁 guard-gate 或绕路）
5. 结局判定：`hermitDead` → **SHADOW**

**验证测试**：`EndingFlowTest.shadowEnding_killHermit`

#### 方式 C：杀守卫且无宝石

1. 不拿 `gem-light`
2. 杀守卫（同方式 A 步骤 1-3）
3. 进入 `throne-hall`
4. 结局判定：`guardDead && !hasGem` → **SHADOW**

**验证测试**：`EndingFlowTest.shadowEnding_killGuardNoGem`

### 3.3 中立结局 NEUTRAL

1. 不拿 `gem-light`，不杀任何人
2. 用对话友善解锁 `guard-gate`（或用钥匙 `key-guard` 开门）
3. 进入 `throne-hall`
4. 结局判定：无 gem → 不是 LIGHT / 声望 OK 无人死 → 不是 SHADOW → **NEUTRAL**

或者：拿了 gem 但杀了守卫（非隐士）→ `guardDead && !hasGem` = false（有 gem），`rep>=0` → LIGHT 的 `!guardDead` = false → 不匹配 LIGHT；SHADOW 条件也不匹配 → NEUTRAL

**验证测试**：`EndingFlowTest.neutralEnding_noGemNoKill`

## 七、Undertale 战斗系统

```
CombatSystem 接口
  ├── CombatEngine（回合制）
  └── UndertaleCombatEngine（UT 弹幕式）
       ├── Bullet — 弹幕实体（圆形/矩形 + AABB碰撞）
       ├── BulletPattern — 4 种图案（wave/burst/scatter/spiral）
       ├── 五阶段：MENU → FIGHT_BAR → ENEMY_TURN → RESULT
       └── ACT 配置化（guard.json / hermit.json 含 actOptions）
```

**游戏中调用**：遭遇菜单按 4 → `engine.startCombat(npcId, CombatMode.UNDERTALE)`

**引擎 API 已就绪**，客户端 UT 画面渲染 (`UtCombatRenderer`) 由 C 负责。
