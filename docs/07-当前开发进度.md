### 2.5 TMX 出口 Y 坐标双重翻转修复（2026-05-26）

**问题**：`GameScreen.checkExitOverlap()` 中 `tiledTopYToGdxY()` 对 TMX 对象 Y 做了二次翻转。
LibGDX 的 `TmxMapLoader` 加载时已将 TMX 的 Y（自上而下）转为 GDX Y（自下而上），
代码再调用 `tiledTopYToGdxY()` 导致南北出口位置互换——
玩家按 W 往上走，碰到的是南出口（lab），而非北出口（theatre）。

**修复**：删除 `tiledTopYToGdxY()` 调用，`objectY` 直接使用 LibGDX 已转换的 GDX Y 坐标。

**验证**：按键日志 + 实际游戏测试确认 WASD 四个方向出口全部正确。

### 2.6 瓦片集绝对路径修复（2026-05-26）

Tiled 存 TMX 时将 tileset 路径写为 Windows 绝对路径
`D:/ruangong_work/.../tiny-dungeon.tsx`，Java 从 classpath 加载 TMX 时无法解析。
已批量替换全部 15 张 TMX 为相对路径 `../tilesets/tiny-dungeon.tsx`。

### 2.7 墙壁缺口修复（2026-05-26 第一次更新）

联调及审计发现多张 TMX 的 `wall` 层在出口位置缺少缺口（整行/列均为墙 tile），导致玩家走到地图边缘后被墙壁挡住，无法与出口矩形重叠。已全部修复：

| 文件 | 位置 | 修复内容 |
|------|------|----------|
| `garden.tmx` | 北墙 row 0 cols 13-16 | 关闭缺口（对应删除幽灵出口） |
| `garden.tmx` | 西墙 row 7-9 col 0 | 2→0（打通 →pub） |
| `garden.tmx` | 东墙 row 7-9 col 29 | 2→0（打通 →armory） |
| `pub.tmx` | 东墙 row 7-9 col 29 | 2→0（打通 →garden） |
| `pub.tmx` | 南墙 row 16 cols 13-16 | 2→0（打通 →cellar，master 合并引入） |
| `theatre.tmx` | 东墙 row 7-9 col 29 | 2→0（打通 →library） |
| `armory.tmx` | 西墙 row 7-9 col 0 | 2→0（打通 →garden） |

此外删除了 `garden.tmx` 北侧幽灵出口对象 `exit-to-outside`（`targetRoomId=outside`），因为 `WorldFactory` 中 garden 无北向引擎连接（garden 仅连接 pub/西、guard-room/南、armory/东）。

## 五、引擎增强（GameEngine）

> 门锁、`useItem` 策略模式、对话/任务/结局等后续由**成员 B** 在 `feature/engineAndPlay` 扩展，详见 **§十三**。

### 5.1 门锁系统

- `movePlayer()` 检查目标房间 `lockId`，未解锁时拒绝进入并记录日志
- `useItem()` 返回 `String`（之前返回 `boolean`），支持效果执行（B 分支已重构为 `UseEffectRegistry`）：

| 效果键 | 格式 | 行为 |
|--------|------|------|
| `unlock` | `unlock:<lockId>` | 解锁指定门，消耗物品 |
| `heal` | `heal:<amount>` | 恢复 HP，消耗物品 |
| `light` | `light` | 光照效果，消耗物品 |
| `reputation` | `reputation:<delta>` | 调整声望，消耗物品 |

### 5.2 谜题链

**金库谜题**：lab(拿 key-vault) → vault(锁) → 使用钥匙 → vault(进入) → 拿 gem-light + gold-coins

**守卫谜题**：office(拿 key-guard) → guard-room(锁) → 使用钥匙 → guard-room(进入) → throne-hall(结局)
