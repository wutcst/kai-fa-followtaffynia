## 三、结局路线详解

进入 `throne-hall` 时 `EndingEvaluator` 判定，条件：

```
LIGHT:  有 gem-light AND 声望 >= 0 AND 守卫未死 AND 隐士未死
SHADOW: 声望 < 0 OR 隐士被杀 OR (守卫被杀 AND 无 gem-light)
NEUTRAL: 其余所有情况
```

### 3.1 光明结局 LIGHT

1. `outside` → 南 → `lab` → 东 → `vault`（需 `key-vault`）
2. 在 vault 拾取 `gem-light`（5 重量）
3. 返回 `outside` → 东 → `pub` → 东 → `garden`
4. 在 garden 南门遇到守卫 → 按 E → 按 1 交流 → 选 1「我是编年史者」
5. 守卫开门（`guard-gate` 解锁），进入 `guard-room` → 南 → `throne-hall`
6. 结局判定：有 gem ✅ / 声望 ≥0 ✅ / 无人死亡 ✅ → **LIGHT**

### 3.2 暗影结局 SHADOW（三种达成方式）

**方式 A**：杀守卫 → 声望变 -15 → **SHADOW**

**方式 B**：杀隐士 → `hermitDead` → **SHADOW**

**方式 C**：杀守卫 + 不拿 gem-light → **SHADOW**

### 3.3 中立结局 NEUTRAL

拒绝祭司试炼 + 拒绝信徒洗礼 → 找学者获得平衡之书 → 学徒切磋得守卫勋章 → 守卫和平通行 → throne-hall 王座前按E → **NEUTRAL**

**叙事**：主角触碰王座，但知晓它不属于自己。已走过光暗两端，选择等待永恒之王，以编年史者之名辅佐左右。

验证测试：`EndingFlowTest` 5 个完整流程测试全部通过。

## 六、Undertale 战斗系统

```
CombatSystem 接口
  └── UndertaleCombatEngine（UT 弹幕式）
       ├── 五阶段：MENU → FIGHT_BAR → ENEMY_TURN → RESULT
       ├── 菜单：1=FIGHT 2=ACT 3=ITEM 4=MERCY
       │    ├── FIGHT → 节奏攻击条（中心区域按 Enter 伤害最高）
       │    ├── ACT → 调查/交谈/威吓（JSON 配置 actOptions）
       │    ├── ITEM → 使用背包物品
       │    └── MERCY → 双连退出（1次嘲讽 + 敌人回合 → 2次和解结束）
       ├── Bullet — 弹幕实体（圆形/矩形 + AABB碰撞）
       ├── BulletPattern — 4 种图案（wave/burst/scatter/spiral）
       ├── BattleLine — 战斗台词系统（start/hp50/hp10/mercy1/mercy2）
       │    └── 底部画中画 Overlay + Enter 继续 + phaseAfterBattleLine 流转
       └── UtCombatRenderer — 弹幕/灵魂/节奏条/HP条/按钮完整渲染
```

**游戏中调用**：按 E 遇 NPC → 按 2 → `engine.startCombat(npcId, CombatMode.UNDERTALE)`

**战斗数据**：`assets/combat/guard.json` + `hermit.json`，含 HP、技能、actOptions、battleLines

**引擎 + 渲染均由 B 完成**，不在待办列表。

## 八、结局系统技术说明

> 供 UI/画面组参考——如需美化结局画面，以下是现有接口和数据流。

### 8.1 判定逻辑

`EndingEvaluator.evaluate(Player, Set<String> defeatedNpcs)`：

```
LIGHT:  背包有 gem-light AND 声望 >= 0 AND 守卫未死 AND 隐士未死
SHADOW: 声望 < 0 OR 隐士被杀 OR (守卫被杀 AND 无 gem-light)
NEUTRAL: 其余所有情况
```

### 8.2 触发时机

`GameEngine.movePlayer()` 中：当 `currentRoom.getRoomId() == "throne-hall"` 时，调用 `endingEvaluator.evaluate()` 并将结果存入 `currentEnding` 字段。

### 8.3 显示逻辑

`GameScreen.render()` 第一行检查 `engine.getCurrentEnding()`：
- 若为 null 或 NONE → 正常渲染游戏
- 若为 LIGHT / SHADOW / NEUTRAL → 跳过所有游戏渲染，仅显示 `drawEndingScreen()`

### 8.4 EndingType 枚举

| 枚举值 | getTitle() | getDescription() |
|--------|-----------|------------------|
| LIGHT | 光明结局 | 你携光明宝石步入王座大厅，Realm 的记忆被重新点亮。 |
| SHADOW | 暗影结局 | 暗影吞噬了王座，编年史者在沉默中离去。 |
| NEUTRAL | 中立结局 | 你触碰了王座，却知晓它不属于你。你已走过光暗两端，了解 Realm 的一切。你选择等待永恒之王，以编年史者之名辅佐左右。 |

### 8.5 当前实现（B 完成，供 UI 组替换）

`drawEndingScreen()` — 黑底 + 0.6s 渐显 + 居中文字（标题 + 描述 + 「按 T 返回标题」）。

**UI 组可改进方向**：
- 替换纯黑底为结局专属像素背景图（`assets/map_bg/throne-hall.png` 加滤镜）
- 加粒子特效（光点/暗影/落叶）
- 加结局音效（`assets/audio/sfx/` 下新增）
- 加「重新开始」按钮替代纯按 T
- 暗影结局加红色滤镜、光明结局加金色光晕

### 8.6 三种结局达成路径

**光明结局**（已可完整走通）：
outside → 南→lab 拿 key-vault → 南→vault 拿 gem-light → 原路返回 outside → 东→pub→东→garden → 南门遇守卫 → 1交谈 → 选「我是编年史者」→ 守卫开门 → guard-room → 南→throne-hall

**暗影结局（三种方式）**：
A) garden 遇守卫 → 2 战斗 → 杀死守卫 → 门自动破开 → guard-room → throne-hall
B) outside → 北→theatre→东→library→北→hidden-shrine → 遇隐士→2 战斗→杀死 → 返回→去 throne-hall
C) 杀守卫 + 不拿 gem-light

**中立结局**：
不拿 gem-light + 不杀任何人 + 进入 throne-hall（或用 key-guard 开门）
