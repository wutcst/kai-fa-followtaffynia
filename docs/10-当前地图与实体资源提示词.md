## 2. 地图通用提示词

复制给 GPT / 图片生成器时，先用这一段，再追加房间专属描述：

```text
Create one original top-down orthographic 2D pixel-art RPG room background for a dungeon exploration game.
Canvas size must be exactly 960x480 pixels, arranged as a 30 columns by 15 rows grid, each tile exactly 32x32 pixels.
Use crisp nearest-neighbor pixel art, no anti-aliasing, no blur, no perspective camera, no text, no UI.
The image must be a clean environment background only: do not draw the player, NPCs, corpses, monsters, dialogue portraits, item labels, floating prompts, damage numbers, or interface panels.
Keep all walls, doorways, large props, and collision-looking objects aligned to the 32x32 grid.
Use a dark lost-realm castle/dungeon mood: stone floors, stone walls, warm torch light, readable walkable paths, restrained color palette.
Leave NPC positions visually empty so game entities can be rendered separately on top.
Output a single PNG, exactly 960x480 pixels.
```

负面提示词：

```text
No characters, no NPCs, no dead bodies, no player, no monsters, no text, no UI, no speech bubbles, no labels, no watermark, no logo, no isometric perspective, no realistic 3D render, no blurry painterly style, no cropped room, no border outside the 960x480 canvas.
```

```text

The in-game collision footprint is about 16x16 px at the feet, while the full sprite is taller like the current player.
Provide four directions: down, up, left, right.
For each direction provide idle frames and 4 walking frames.
Also provide hit frame, attack/threat frame, and a corpse frame lying on the ground.
No background, no UI, no text, no shadow baked outside a subtle pixel shadow under the feet.
```

## 7. 后续接入规则

1. 新底图替换 `assets/map_bg/*.png` 后，所有 PNG 必须统一为 `960×480`。
2. 对应 TMX 的 image layer 应取消旧 offset，图片 width/height 统一为 `960/480`。
3. TMX `objects` 层继续保存 `spawn`、`exit`、`npc`、`door` 等对象；碰撞仍由 `wall` 层非零格控制。
4. NPC 实体由 `npcId` 唯一索引；同一个 NPC 在一个房间只能渲染一个实体。
5. NPC 死亡后保存 `dead=true` 和死亡像素位置；地图上渲染 corpse frame，不再移动，不再交互。
6. `guard` 是同一实体：活着时可以在 `garden` / `guard-room` 按剧情切换；死亡后固定在死亡地点。

## 8. 门位硬规范

AI 生成地图时最容易出错的是门。当前工程里真正能进出的区域来自 TMX 的 `exit`
对象，不来自 PNG 里看起来像门的位置。因此生成底图必须遵守：

1. 只在下表列出的出口位置画门、门洞、铁栅栏或明显通道。
2. 没有列出的墙面不要画门，不要画封闭大门，不要画疑似出口。
3. 如果某处只是装饰门，必须画成被砖封死、被柜子挡住或明显不可通行。
4. 出口矩形附近至少留出 2 格宽的视觉通道，不要放桌子、炉子、王座、书架、石柱等大型障碍。
5. 底图生成后先做门位 overlay 检查：红框必须落在视觉门洞内，不能落在实心墙或大型装饰上。
