### 0.3 光影规则

- **火把光晕**：以火把火焰中心为圆心，半径 48px 的径向渐变。中心 blend 系数 0.35，边缘线性衰减到 0。叠加色为火把火焰色。
- **宝石辉光**：半径 32px，中心 blend 0.30，叠加宝石辉光色。
- **锻造炉光**：半径 80px，中心 blend 0.40，叠加锻造火焰色。
- **传送阵蓝光**：半径 48px，中心 blend 0.20，叠加符文蓝色。
- **无火把区域**：使用环境暗色（在基础色上叠加 10% 黑色）。
- **墙壁阴影**：墙壁与地板交界处有一条 2px 的阴影线（在墙壁色上叠加20%黑色）。
- **砖块纹理**：每块砖 16×8 px，砖与砖之间有 1px 暗色灰缝。相邻行砖块错开半块砖（8px）。

### 0.4 门绘制规范

**水平门（顶部/底部墙壁）：**
- 位置：门中心 x = 墙壁中央，y = 墙壁内缘
- 尺寸：宽 24px，高 40px
- 门框：2px 深色边框
- 上锁时：门中央画 8×8 金锁标记
- 铁栅栏门：使用铁门色 + 垂直栅栏条（每 4px 一条）

**垂直门（左/右侧墙壁）：**
- 位置：门中心 y = 墙壁中央，x = 墙壁内缘
- 尺寸：宽 40px，高 24px
- 其他同上

### 0.5 NPC 绘制规范

所有 NPC 用双色矩形块表示，站立姿态：
- 身体：10×16 px（宽×高），主色
- 头部：8×8 px，亮色，在身体正上方偏移 2px
- 守卫额外：右手持 2×20 px 长矛（铁灰色），从身体右侧向上延伸

## §2 房间拓扑关系

```
            hidden-shrine (隐士 NPC)
                 │ N
 theatre ──── library ──── teleport-alcove (传送)
    │ S          │ W
    │            │
office ─ outside ── pub ──── garden ──── guard-room ──── throne-hall
  (E)     │        │  S      │  S  (锁)    │  S          (结局判定)
          │ S      │         │              │
         lab ── vault      cellar      armory ──── forge
            S  (锁)                      │  S    (商人 NPC)
                                        forge
```

- **起点**：outside（地牢入口广场）
- **锁门**：vault（需 key-vault，在 lab）、guard-room（需对话/钥匙/击杀守卫）
- **NPC 位置**：
  - guard：garden（外侧）+ guard-room（内侧）
  - hermit：hidden-shrine
  - merchant：forge
- **魔法饼干随机位置**：cellar / library / hidden-shrine（三选一）
- **结局触发**：进入 throne-hall 时自动判定
