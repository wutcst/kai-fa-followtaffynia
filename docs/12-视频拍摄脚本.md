# 【武理26软工实践】Chronicle of the Lost Realms — 视频拍摄脚本

> 时长：5-8 分钟
> 标题前缀：【武理26软工实践】

---

## 第一段：开场（30秒）

**画面**：黑屏 → 游戏标题渐显 → 切入游戏主界面（outside 房间，角色站立，像素地牢背景）

**配音**：
> "失落 Realm 编年史——这是我们小组基于 World of Zuul 开发的像素风 2D 桌面 RPG。欢迎来到失落王国。"

**操作**：角色原地站 2 秒，然后开始移动。

---

## 第二段：世界探索（60秒）

**画面**：演示在 outside 移动 → 进入 theatre → 进入 pub → 展示世界地图（按 M）

**配音**：
> "游戏世界由 15 间互联地牢房间组成，非线性探索。按 M 可以打开世界地图，查看已探索区域。每个房间都有独特的像素背景和物品——纸条、火把、钥匙、装备散落在各处。"

**操作**：
1. outside → 南 → lab，捡 key-vault（锈钥匙）
2. lab → 南 → vault（用钥匙开门），捡 gem-light（光之宝石）
3. 按 I 打开背包展示物品，按 X 查看详情

---

## 第三段：NPC 对话系统（45秒）

**画面**：回到 outside → pub → garden → 南门遇到守卫 → 按 E → 按 1 交谈 → 选择对话选项

**配音**：
> "按 E 与 NPC 互动。对话系统支持分支选项——你的选择会影响剧情走向。守卫可以用对话和平通行，也可以选择战斗。"

**操作**：展示对话画中画——NPC 文本 + 选项 + Enter 翻页。

---

## 第四段：Undertale 战斗系统（120秒）⭐ 重点

**画面**：进入战斗 → 展示完整的 UT 战斗循环

**配音**：
> "接下来是本项目最核心的技术亮点——Undertale 式弹幕战斗系统。"
>
> "1 键 FIGHT 是节奏攻击——注意观察浮动条，在中心区域按下确认，越靠近中心伤害越高。"
>
> "2 键 ACT 可以调查、交谈或威吓敌人——每种行动都会产生真实的战斗效果。"
>
> "4 键 MERCY 是饶恕——第一次会被嘲讽，敌人照常攻击。第二次才真正和解，战斗结束后自动切入对话。"

**操作**：
1. 进战斗 → 开战台词画中画弹出 → Enter 继续
2. 选择 FIGHT → 节奏条演示（最好打出"完美"）
3. 弹幕躲避阶段（WASD 移动灵魂）
4. 选择 ACT（展示效果提示文字）
5. 第 1 次 MERCY → 嘲讽台词 → Enter → 弹幕照常
6. 第 2 次 MERCY → 和解台词 → Enter → 战斗结束 → 自动对话

---

## 第五段：三条结局路线（60秒）

**画面**：快速展示三条路线的关键节点

**配音**：
> "游戏设计了三种结局——光明、暗影、中立，各有独立的达成路径。"
>
> "光明结局需要收集光明印记、光之宝石和守卫勋章，和平说服守卫后走向王座。"
>
> "暗影结局需要接受暗影之契，杀掉守卫，以武力闯入王座大厅。"
>
> "中立结局则需要平衡之书，在光明与暗影之间走第三条路。"

**操作**：
1. 快速展示物品栏中的结局关键物品
2. 走到 throne-hall → 王座前 → 按 E → 结局画面渐显
3. 展示结局标题 + 描述文字

---

## 第六段：技术亮点 + 结尾（45秒）

**画面**：快速滚动代码 + GitHub Actions 截图 + 测试结果

**配音**：
> "项目采用 Java 8 + LibGDX 框架开发，Maven 构建管理。代码分为 Client、Engine、Domain、Infra 四层，数据驱动——所有 NPC 战斗参数和对话均通过 JSON 配置。"
>
> "81 个自动化测试覆盖核心模块，GitHub Actions 在每次推送时自动编译和测试。"
>
> "感谢观看——失落 Realm 编年史，GitHub 仓库链接见视频简介。"

## 录制建议

- 使用 OBS 录制，分辨率 1920×1080
- 游戏窗口最大化，隐藏任务栏
- 配音单独录制后合成
- 可在关键操作处加文字标注（如 "FIGHT"、"MERCY×2"）
- 背景音乐：使用游戏自带 BGM（dungeon.wav / combat.wav）
- 结尾放 GitHub 链接二维码
